# 等 episode 预算对照报告

在同一 64 隐状态、时域 4、4 观测、2 动作的 POMDP 与 73 模型候选类上，对比 ours 和 OMLE。随机种子为 0、1、2。两种方法在每个种子、每个检查点使用相同累计 episode 数：6,000 到 999,996，共 9 个预算点。精确全策略 TV 用有限时域动态规划计算。目标精度按 \(\epsilon=0.4\sqrt{6000/N}\) 随预算标记。

## 调用次数的解释与纠正

这项实验没有训练神经网络。普通 MLE 在 73 个固定候选 PSR 中选择完整日志似然最大的模型。

ours 的 3 次拟合由代码中的预算切分直接决定：`batch = N // 12`，每轮采集 `6 * batch = N/2` 个 episode，因此只在 0、N/2、N 三个位置拟合和规划。其中第一次使用空数据，只有后两次使用采集数据。该曲线是预设两批数据后的准确性比较，不能作为“算法自然只需 3 次更新”或“调用数基本不随精度增长”的证据。

本轮所有 ours 记录的 `stopped` 均为 False：预算用尽时，没有一个运行触发 bonus 停止。代码保留了 bonus 提前停止判断，并没有强制忽略停止条件；先前报告对此的描述不准确。

OMLE 每轮执行 3 个 core 干预 episode，计划更新次数为 N/3。较大预算下，置信集可能只剩一个模型，后续搜索已平凡；汇总表的 `omle_nontrivial_calls` 单独记录仍存在候选模型对的次数。计划调用数增长同样受到更新日程控制。

这组结果可以说明“在指定两批采样日程和同样本预算下的预测精度”，但不能验证达到停止证书所需的调用复杂度。要检验额外更新是否有用，需在同一 episode 预算和精度目标下比较多种更新频率，并另行记录按论文批量公式与 bonus 规则自然停止的轮数。

## 复现与数据

运行命令：

```sh
.venv/bin/python experiments/psr_mle_toy/run_queue_equal_budget.py \
  --output experiments/psr_mle_toy/results/queue_pomdp/equal_episode_final \
  --seeds 3 --budgets 6000 12000 24000 48000 96000 192000 384000 768000 999996
```

`equal_budget_runs.csv` 保存逐种子数据；`equal_budget_summary.csv` 保存汇总；`equal_budget.pdf/png` 为图。该实验比较同样的 episode 预算与经验预测误差，不代替前一实验的 bonus 停止证书审计。
