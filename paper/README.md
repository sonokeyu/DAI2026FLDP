# ACM SIG Proceedings Paper Template

This directory contains the ACM SIG Proceedings LaTeX template corresponding to the ACM/Overleaf `sigconf` template.

The editable sample is:

```text
acm-template/samples/sigconf.tex
```

The generated ACM class and bibliography styles are included in `acm-template/` so the template can be compiled locally without relying on a globally installed `acmart` package.

For DAI review submissions, use the conference instructions and switch the document class to the required anonymous review options when applicable. Replace the sample rights, conference, CCS, author, and bibliography fields before submission.
