# Learning Predictive State Representations with Ordinary Maximum Likelihood and Model Planning

Build from this directory with a full TeX Live installation.

~~~sh
latexmk -pdf main.tex
~~~

The entry point is main.tex. The body files follow a hidden-type routing example through the stopping certificate, executable diagnostic experiments and the progress proof. A specialization gives the result for observable Markov states. The appendix contains likelihood calibration, sample budgets, numerical evaluation and extensions. The author block is open for the authors' names and affiliations.
